04 · Agents get less carefulAI safety research

AI safety research

Give a model tools, it gets worse at saying no.

68.7%relative increase in refusal‑failure rate when models use tools agentically
  • Tested across GPT‑5.4, Claude Opus 4.6/4.7, Gemini‑2.5/3.1‑Pro, plus open‑weight Qwen, Kimi and GLM, every model moved the same direction.
  • Researchers' own theory: "safety focus displacement," attention shifts to the tool's result instead of whether to answer at all.

For the studio: don't assume a model's usual guardrails hold once it's agentic. Directly relevant anywhere Hex, Flux or Sage wire AI agents into file, browsing or shell access.

Confirmed
Sources: arXiv:2610.03938
05 · Newer isn’t saferCode security research

Code security research

Bigger models write better code. Not safer code.

  • 32 models across seven families, tested on five languages and 31 vulnerability categories.
  • No model family closes the gap between code that passes functional tests and code that passes security tests, not even Google's Gemini 3.1 Pro.
  • Compact "mini"/"flash" variants generally produced less secure code than their flagship siblings.

For the studio: re‑run security checks after every model change. A smarter model is not automatically a safer one, especially the cheap tier.

Confirmed
Sources: arXiv:2610.08240

07 · Where reports disagree, and sourcesFine print

Fine print

Three things we are not quoting as fact.

  • Surface Laptop Ultra's top price is $5,899.99. A separate figure, $5,999, is for the different Surface RTX Spark Dev Box. Outlets have mixed these up, we haven't.
  • RTX Spark's memory bandwidth is reported as "roughly 300GB/s" by one outlet only, with no second source confirming it. Treat it as likely, not confirmed.
  • Some Oct 6‑7 coverage conflates this week's OpenAI manuscript release with a separate Sept 8 priority dispute with NYU. Different stories, not a new development.

For the studio: when two outlets disagree, say so instead of picking the tidier number.
